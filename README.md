# 왕전초 타이머왕 (Wangjeon Timer King)

숫자가 사라진 뒤 **속으로 세어**, 목표 시간에 딱 맞춰 멈추는 블라인드 초 맞추기 게임입니다.
`♡왕전초 연산왕!♡`와 같은 왕전초 시리즈예요.

**바로 플레이:** https://chohanui2-home.github.io/wangjeon-timer/

## 특징

- **6가지 목표 시간** — 5초(초보) · 7.77초(행운) · 10초(국민) · 15초(집중) · 20초(인내) · 랜덤(매판 3~15초에서 새 목표). 화면 맨 아래 탭으로 바로 변경
- **3단계 숫자 숨김** — 잠깐 보기(목표의 30%까지만 보임) · 처음부터 안 보기(시작하자마자 가림) · 계속 보기(연습용)
- **정확한 측정** — `performance.now()` 기반. 화면은 `00.00초`, 결과는 **ms(0.01초) 단위**까지 계산해 `-0.03초 (30ms 빠름!)`처럼 알려 줍니다
- **등급 배지** — 👑 전설의 인간시계 · ✨ 소름 돋는 감각! · 🔥 거의 완벽! · 👍 굿 타이밍 · 🐣 조금만 더!
- **기록 저장** — 모드×난이도별 최고 기록(오차가 가장 작은 기록)과 최근 기록 5개를 브라우저에 저장
- **혼자서도 재미있게** — 마스코트 표정 변화(기대·집중·눈 가리기·환호·다독임), 0.05초 이내면 폭죽, 효과음(음소거 가능)
- **친구에게 공유** — 결과 화면의 공유 버튼(휴대폰 공유 시트 / 링크 복사)
- **앱처럼 설치** — 홈 화면에 추가하면 전체화면 앱처럼 열립니다
- PC에서는 `Space`·`Enter` 키로도 시작·멈춤

## 파일

- `index.html` — 게임 전체가 들어 있는 단일 파일. 외부 CDN·폰트·이미지 0개(그림은 인라인 SVG, 소리는 Web Audio API). 파일 하나만 보내도 그대로 열립니다.
- `app_template.html` — 빌드용 템플릿(아이콘 자리표시자 포함)
- `build.py` — 아이콘 주입·단일 파일 규칙 검사 후 `index.html` 생성
- `test_app.py` — QuickJS로 게임 스크립트를 실행해 타이머 계산·오차/등급·숨김 기준·랜덤 목표·기록 저장·키보드·화면 이탈 처리를 검사하는 테스트

## 다시 빌드하기

```bash
python3 build.py      # index.html 생성 (단일 파일 검사 포함)
python3 test_app.py   # 테스트 (quickjs 파이썬 모듈 필요)
```

## 게임 규칙

1. 아래 탭에서 목표 시간을 고르고, 난이도를 정합니다.
2. `시작!`을 누르면 **3·2·1** 카운트 뒤에 시계가 출발합니다.
3. 숫자는 난이도에 따라 가려집니다. 속으로 세어 보세요.
4. 목표에 딱 맞는 순간에 `멈춰!!`를 누르면 오차와 점수가 나옵니다.
5. 오차 0.05초 이내면 👑 전설의 인간시계!
